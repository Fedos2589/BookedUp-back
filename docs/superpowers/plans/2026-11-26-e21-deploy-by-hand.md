# E21 Выкладка на VPS — что делает человек руками

Цель: выложить BookedUp в интернет, чтобы друзья и знакомые попробовали до включения подписки (E11).
Решение пользователя (2026-11-26): один VPS, docker compose, Caddy с HTTPS, один домен на фронт и API.

Это шаги, которые не делает код: покупки и аккаунты. Задачи на код (Dockerfile, compose, Caddy, миграции, бэкапы,
деплой) нарезает Opus в `2026-11-26-e21-deploy.md` (и план фронта в BookedUp-front).

## 1. Домен (около 10–15 $ в год)

- [ ] Купить в Cloudflare Registrar, Namecheap или Porkbun. Название любое, например `bookedup-app.com`.
- Одного домена без поддоменов хватит: фронт и API живут на нём вместе (API на `/api`).

## 2. VPS (около 5–8 $ в месяц)

- [ ] Hetzner Cloud: тариф CX22 или аналог, 2 vCPU и 4 ГБ RAM. Postgres, Redis и Node помещаются; на 1 ГБ будет тесно.
- [ ] Регион ближе к друзьям, например Германия или Финляндия.
- [ ] ОС Ubuntu 24.04.
- [ ] При создании добавить свой SSH-ключ.
- Если Hetzner не примет карту: Aeza, Timeweb Cloud или DigitalOcean. План от провайдера почти не зависит.

## 3. DNS

- [ ] В панели домена создать запись `A` с `@` на IP сервера. После этого Caddy сам получит HTTPS-сертификат.

## 4. Telegram-бот

- [ ] Создать бота через @BotFather, получить токен и username. Нужно до первого запуска.
- Без бота нет онлайн-записи (решение D7 эпика E7b).

## 5. Что нужно для первого запуска

- [ ] IP и SSH-доступ к серверу;
- [ ] домен;
- [ ] токен и username бота.

WhatsApp, email и Web Push на первый тест не нужны: без ключей они выключены.
