# E21 Выкладка на VPS — что делает человек руками

Цель: выложить BookedUp в интернет, чтобы друзья и знакомые попробовали до включения подписки (E11).
Решение пользователя (2026-11-26): один VPS, docker compose, Caddy с HTTPS, один домен на фронт и API.

Это шаги, которые не делает код: покупки и аккаунты. Задачи на код (Dockerfile, compose, Caddy, миграции, бэкапы,
деплой) нарезает Opus в `2026-11-26-e21-deploy.md` (и план фронта в BookedUp-front); там же точные шаги R1–R19.

## 1. Домен (около 10–15 $ в год)

- [ ] Купить в Cloudflare Registrar, Namecheap или Porkbun. Название любое, например `bookedup-app.com`.
- Одного домена без поддоменов хватит: фронт и API живут на нём вместе (API на `/api`).

## 2. VPS (около 5–8 $ в месяц)

- [ ] Hetzner Cloud: тариф CX22 или аналог, 2 vCPU и 4 ГБ RAM. Postgres, Redis и Node помещаются; на 1 ГБ будет тесно.
- [ ] Регион: Германия или Финляндия (друзья в Европе, Грузии и Таиланде). Тип x86, не Arm.
- [ ] ОС Ubuntu 24.04.
- [ ] При создании добавить свой SSH-ключ.
- Если Hetzner не примет карту: Aeza, Timeweb Cloud или DigitalOcean. План от провайдера почти не зависит.

## 3. DNS

- [ ] В панели домена создать запись `A` с `@` на IP сервера. После этого Caddy сам получит HTTPS-сертификат.

## 4. Telegram-бот

- [ ] Создать бота через @BotFather, получить токен и username. Нужно до первого запуска.
- Без бота нет онлайн-записи (решение D7 эпика E7b).

## 5. Копии базы вне сервера (бесплатно на старте)

- [ ] Backblaze B2: аккаунт, приватный bucket с Object Lock (включается только при создании, 30 дней), ключ только на
      этот bucket. Точные шаги — R7 в `2026-11-26-e21-deploy.md`.
- [ ] healthchecks.io: две проверки (бэкап каждый час, проверка восстановления раз в неделю), оповещения на почту.
- [ ] Менеджер паролей: запись «BookedUp server» — туда копии `.env` и `api.env` сервера (R8) и пароль sudo
      пользователя `deploy` (R6). Без `.env` копии базы не прочитать.
- Зачем: если сервер, его диск или аккаунт Hetzner пропадут, база восстановится из B2 (не старше часа). Бэкапы
  Hetzner удаляются вместе с сервером, поэтому их одних мало.

## 6. Почта на домене (бесплатно)

- [ ] Пересылка `privacy@<домен>` и `hello@<домен>` на ваш ящик: Cloudflare Email Routing или пересылка у регистратора.
      Нужна для политики конфиденциальности (P2) — по этому адресу пишут, чтобы удалить данные. Шаги — R17.

## 7. Письма для восстановления пароля (P1, бесплатно до 3000 писем в месяц)

- [ ] Resend: аккаунт, домен с DNS-записями (SPF, DKIM), ключ только на отправку. Шаги — R18. Нужен после выкладки P1.

## 8. Данные ИП для политики конфиденциальности (P2)

- [ ] Полное имя ИП, регистрационный номер, адрес в Грузии — как в реестре. Попадут в публичный репозиторий. Шаг — R19.

## 9. Что нужно для первого запуска

- [ ] IP и SSH-доступ к серверу;
- [ ] домен;
- [ ] токен и username бота;
- [ ] ключ B2, адреса двух проверок healthchecks.io.

WhatsApp, email и Web Push на первый тест не нужны: без ключей они выключены.
